Diese Subtask verbindet die neue Aktionskarte mit dem bestehenden Flow zum Senden von Admin-Nachrichten.

Ziel

- Die Karte soll mindestens die Aktion `Admin-Nachricht senden` enthalten und damit denselben technischen Nachrichtenpfad wie bisher nutzen.

Umfang

- In der Aktionskarte eine klar benannte Aktion `Admin-Nachricht senden` einbauen.
- Von dort in den bestehenden Dialog oder Flow zum Erstellen und Senden einer Admin-Nachricht verzweigen.
- Sicherstellen, dass der Zieluser korrekt aus der Aktionskarte uebernommen wird.
- Texte so anpassen, dass die Funktion eindeutig als Admin-Kommunikation erkennbar bleibt.

Erfolgskriterien

- Ein Admin kann aus der Aktionskarte heraus eine Admin-Nachricht an den gewaehlten User verfassen.
- Der bestehende technische Versandpfad wird weiterverwendet.
- Im UI entsteht nicht der Eindruck, dass die Nachricht eine Antwort auf den gerade sichtbaren Post oder Reply ist.
