# Mission

Break the task down into subtasks, which will allow for its step-by-step implementation.

If the current task has not yet been broken down into subtasks, create an initial breakdown into
subtasks. If there is a breakdown from the previous round, update the subtask breakdown according
to the comments from the review.

# Task Coordination

Follow the shared task-coordination rules in [`tasks/Coordination.md`](../../../tasks/Coordination.md).
Read `Description.md` and `ArchitectureNotes.md` for guidance.
If there are findings from a previous review, they may already be recorded in `TaskSplitReview.md`.
